# UI 개편 수동 QA 체크리스트 (Avalonia)

자동 검증 완료: 단위 테스트 28개 통과, Avalonia 프로젝트 경고 0·오류 0, 설치 페이로드 빌드, `--verify-install` 종료 코드 0.
아래는 실제 PC에서 확인해야 하는 항목이다.

## 보호 동작 회귀
- [ ] 앱 추가(설치 앱 선택·실행 파일 직접 찾기) → 토글로 잠그기 → 풀기, 삭제
- [ ] 실행 정책 저장(유예 분, 시간대, 전용 PIN) 후 서비스 동기화(보호 정책 오류 메시지 없음)
- [ ] 잠긴 앱 실행 시 새 Gate 창 표시, 다크 모드 대응, 잘못된 PIN/취소
- [ ] 단축키, 유휴 자동 잠금, 트레이 숨김/복귀, 세션 잠금·절전 후 재잠금, 단일 인스턴스
- [ ] PIN 해제 후 마우스 커서가 사라지지 않음(`protection.log`의 `pin-unlock/...`)
- [ ] 첫 실행(PIN 없음)에서 3페이지 온보딩

## 화면
- [ ] 라이트/다크/고대비에서 모든 화면이 읽힘
- [ ] 100/150/200% 배율, 창 폭 900 미만(레일 접힘, 상세 패널 전체 화면), 최소 640×480
- [ ] 키보드만으로 모든 조작, 포커스 표시, Narrator가 행을 "이름, 잠김"으로 읽음
- [ ] 시스템 애니메이션 끔: 흔들림·열림 모션 생략
- [ ] 긴 앱 이름·경로 말줄임 + 툴팁, 앱 0개 빈 상태, 검색 결과 없음

## 설치
- [ ] 신규 설치 및 beta.8 → 신규 빌드 업그레이드 후 시작 메뉴 검색, 앱 삭제 시 정상 제거
- [ ] Gate 창 표시 지연 300ms 이내(체감)
