# 위협 모델

이 문서는 `DESIGN-backend-redesign.md` §2에서 확정한 내용입니다.

| 행위자 | 방어 여부 | 근거 |
|---|---|---|
| 같은 PC의 **표준 사용자**(관리자 아님) 또는 권한 상승하지 않은 세션 | **방어 대상** | 제품이 존재하는 이유 |
| 권한 상승할 수 있는 **관리자** | 방어하지 않음. 변조는 **탐지해서 복구하고 표시**만 함 | 서비스 중지, 레지스트리 삭제, 드라이버 설치 등 막을 방법이 없음 |

## 방어 대상 행위자에 대한 보장

- 잠긴 일반 exe를 다음 방법으로 실행해도 PIN 없이는 사용할 수 없습니다.
  - 정상 실행: IFEO가 Gate를 띄웁니다.
  - `DEBUG_PROCESS` 플래그로 실행해 IFEO를 우회하는 경우
  - 이름을 바꾸거나 다른 위치에 복사해서 실행하는 경우(크기와 SHA-256이 같은 파일)
  - 위 우회는 모두 프로세스 감시기가 종료합니다.
- 잠긴 앱의 창은 보이지 않습니다. 이미 실행 중이던 앱도 마찬가지입니다.
- 표준 사용자는 다음을 할 수 없습니다.
  - 창 에이전트 종료(프로세스 소유자와 DACL을 SYSTEM으로 제한)
  - 정책 파일(`policy.json`) 수정
  - 다른 사용자의 Gate 요청 읽기(`Gate\Requests`는 파일 만들기만 허용)
  - PIN 해시 읽기(`secrets.json`은 SYSTEM과 Administrators만 접근)
- **실패할 때는 잠금을 유지합니다(fail-closed).**
  - 서비스가 멈춰도 IFEO 규칙은 남아 있습니다.
  - 서비스가 응답하지 않으면 Gate는 실행을 거부합니다.
  - 에이전트가 비정상 종료해도 숨긴 창을 복원하지 않습니다.
  - 창 복원은 오직 "정책상 해제"일 때만 일어납니다.

## 방어하지 않는 것

- 관리자 권한을 가진 행위자(서비스 중지·삭제, IFEO 키 삭제, 파일 직접 수정, 디버그 권한으로 에이전트 종료).
  변조는 서비스가 감지해 규칙을 복구하고 `Runtime\status.json`의 `TamperEvents`에 기록합니다.
- 서명자 기준 일치(다른 빌드의 같은 앱)와 64MB를 넘는 파일의 해시 일치.
- 커널 드라이버를 쓰는 우회.

## 데이터 폴더 권한 (`C:\ProgramData\Windows App Protector\`)

| 경로 | SYSTEM | Administrators | Users |
|---|---|---|---|
| `policy.json`, `secrets.json`, `ui.json` | 모든 권한 | 모든 권한 | — |
| `Runtime\` (`enforcement.txt`, `status.json`) | 모든 권한 | 모든 권한 | 읽기 |
| `Runtime\attempts\` | 모든 권한 | 모든 권한 | — |
| `Gate\Requests\` | 모든 권한 | 모든 권한 | 이 폴더에만 파일 만들기 |
| `Gate\Responses\` | 모든 권한 | 모든 권한 | — (응답 파일마다 요청자만 읽기) |
| `Logs\` | 모든 권한 | 모든 권한 | 읽기 |

서비스가 시작할 때마다 이 권한을 다시 적용합니다.
